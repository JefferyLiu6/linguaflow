# English reference notes

200 notes: 31 original curriculum notes and 169 grammar/usage additions.

Canonical teaching content is in [contrasts.jsonl](contrasts.jsonl); source metadata is in [references.json](../references.json). Each JSONL line is one note. All new notes have three original examples, an explained counterexample and a development question. Human review is pending.

`version: 2.0.0` is the existing note/bundle format. `dataset.json` records the separate corpus revision `2026-11-16.200`. The drill coverage file maps existing exercises only; new notes expand freeform help without inventing authoring links.
